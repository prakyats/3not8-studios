# 3not8 Studios

Website for 3not8 Studios.

## Status

First draft in progress, to set the overall direction for team review. Content and section structure are not final.

## Stack

- [Astro](https://astro.build) for the site, shipping minimal JavaScript by default
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- [GSAP](https://gsap.com) with ScrollTrigger for scroll animation
- [Three.js](https://threejs.org), loaded only on sections that need 3D

## Project layout

- `brand/` logos, brand graphics and the brand guidelines
- `docs/website-brief.md` the brand summary for building the site

## Requirements

- Node.js 24+
- npm 11+
